# Building Synco Extension from source (for addons.mozilla.org reviewers)

The extension is written in TypeScript (`src/`) and bundled with [esbuild](https://esbuild.github.io/) into one
JavaScript file per entry point. The output is **not minified** and contains **no third-party runtime library**: every
dependency in `package.json` is a build or test tool. The build is deterministic (pinned versions, no timestamps).

## Environment

| Requirement | Version | Notes |
| --- | --- | --- |
| Operating system | Linux or macOS (tested on Fedora Linux 44, x86_64) | Windows: use WSL 2 with a Linux distribution |
| Node.js | 22 or later (tested with 22.22.2) | runs the build script and esbuild |
| Bun | 1.3.14 (exact) | only installs the pinned dependencies from `bun.lock` |
| bash, curl | any recent version | used by the setup script |

Network access is needed once, to download Bun (if missing) and the npm packages listed in `bun.lock`.

## Installing the tools

**Node.js 22** — from https://nodejs.org/en/download (LTS 22.x), or with nvm:

```sh
curl -fsSL https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
# open a new shell, then:
nvm install 22
```

**Bun 1.3.14** — installed automatically by `scripts/amo-build.sh` into `./.bun-amo` if the `bun` command is missing or
has another version. Manual install:

```sh
curl -fsSL https://bun.sh/install | bash -s "bun-v1.3.14"
```

## Step-by-step build

From the root of the extracted source archive (`synco-extension-<version>-source.zip`):

```sh
bash scripts/amo-build.sh
```

The script checks the OS and the Node.js version, installs Bun 1.3.14 if needed, then runs the build steps, which
can also be run by hand:

```sh
bun install --frozen-lockfile        # 1. exact dependency versions from bun.lock
node scripts/make-ui-assets.mjs      # 2. regenerate src/ui/icons.css from the SVG files in assets/
node scripts/build.mjs --prod        # 3. production build → dist/chrome/ and dist/firefox/
```

Step 2 rewrites the committed `src/ui/icons.css` with identical content; it only shows how that file is produced.

Do not run step 2 with Bun: the build is only supported with Node.js.

## Result

`dist/firefox/` contains the add-on. Each of its files is identical, byte for byte, to the corresponding file in the
submitted `synco-extension-<version>-firefox.zip` (compare with `sha256sum` or `diff -r` after unzipping the add-on;
compare file contents, not the `.zip` checksum, which may vary with the zlib version).

## Where the code comes from

| Add-on file | Source |
| --- | --- |
| `background.js` | `src/background/` (bundled) |
| `content.js` | `src/bridge/content.ts` (bundled) |
| `popup.js`, `options.js`, `prompt.js` | `src/ui/` (bundled) |
| `*.html`, `ui.css`, `icons/*.png` | copied as is (list in `scripts/lib/entries.mjs`) |
| `icons.css` | copied from `src/ui/icons.css`, generated by `scripts/make-ui-assets.mjs` from `assets/**/*.svg` (Bootstrap Icons, MIT, and the Synco logo) |
| `manifest.json` | `manifests/base.json` + `manifests/firefox.json`, origins from `config/origins.json` |

More detail (French): `doc/build-reproductible.md`.
